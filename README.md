
# MediBMI - BMI Calculator

A web-based BMI (Body Mass Index) Calculator developed using **Python Flask, HTML, and CSS**. The application allows users to enter their personal information and calculate their BMI using their height and weight.

Based on the calculated BMI, the application displays the user's BMI category along with general diet, exercise, and health recommendations.

---

## Features

- User information page for entering name and age
- BMI calculation using height in centimeters and weight in kilograms
- Automatic BMI category detection
- BMI categories:
  - Underweight
  - Normal Weight
  - Overweight
  - Obese
- General diet recommendations for each BMI category
- Exercise recommendations
- Health and wellness tips
- Medical-themed user interface
- Animated user interface
- Responsive design
- Dynamic background image transition
- Flask routing and HTML templates
- Session-based storage of user name and age

---
